# 六周训练 · 总规划

训练期 2026-11-16 — 2026-12-27（6 周）｜训练原型：第十七届服创大赛 A23 文档理解与多源数据融合｜形式：个人独立完成

**本文只回答一件事：这六周不能偏到哪里去。**

每周做什么、怎么做、交什么、怎么算通过，**全部由各周任务书决定**，本文不复述、不摘要、不校验。  
冲突裁决：**方向以本文为准，执行以任务书为准。**

---

## 1. 练的是什么

不是"做完一个系统"，而是**独立完成一次可交接的交付**：解析 → 抽取 → 填写 → 验证，四段全通，且别人能接手复现。

三条成功定义，缺一条即为未达成：

| 判据  | 标准                     |
| --- | ---------------------- |
| 能跑通 | 新环境按 README 启动，浏览器里能演示 |
| 能验证 | 准确率有数字，数字可复现，错误能归因     |
| 能交接 | 没参与过的人只看文档能接手，并复现同样的数字 |

准确率的具体口径、抽样方法与比对基准由第 4 周任务书定义；本文只要求数字可复现、错误能归因，不规定分母。

"跑得起来但交接不了"= 不通过。这是本训练与"交个作业"的分界线。

## 2. 两档：不是两个项目，是一条曲线的两个刻度

同技术栈、同链路、同数据、同交付形态。差别只在两处：

- **任务量**：第二档在第一档全部任务之上，多一批增量任务。
- **指导粒度**：第一档给完整步骤；增量任务只给目标与验收，不给路径。

因此两档真正考的不是"会不会更多技术"，而是——  
**第一档考"按步骤把事做成"；第二档考"没有步骤时还能把事做成"。**

第二档的第一段必须照第一档完整走完。它是第二段唯一的参照物，不是可跳过的重复劳动；第二段撤掉步骤，抬的是规划与检索能力，不新增概念。

## 3. 五条不可让步

1. **技术栈锁定**：Vue3 + FastAPI + SQLite + DeepSeek API。六周教交付，不教选型；"换个框架更快"的讨论到此为止。
2. **链路完整优先于功能丰富**：四段必须全通，宁可每段浅。缺一段的漂亮系统不算完成。
3. **可验证性不跳过**：报不出可复现数字的功能，视为没做。这是最容易被牺牲、最决定成败的一条。
4. **新概念每周不超过 1 个**：难度靠"撤掉步骤"和"提高标准"来加，不靠堆要求项——要求一多，人就会掉进"抄得下来、讲不出来"。
5. **个人独立**：提交的代码须能自述，讲不清的部分不通过。唯一设计好的协作点是第 6 周交叉验收。

## 4. 明确不做

- 用户体系、权限、多租户
- 模型微调、自训、私有化部署
- 前端工程化（路由、状态管理、组件库选型）
- 并发与性能优化（单文档响应时间达标之外一律不做）
- 移动端、线上部署
- 样本数量军备竞赛
- 第 6 周新增业务功能

## 5. 六周节奏（只到能力跃迁）

| 周 | 跃迁                         |
| - | -------------------------- |
| 1 | 代码进仓库、别人看得懂 —— 工程习惯立起来     |
| 2 | 文件 → 统一数据：多格式进，一个 schema 出 |
| 3 | 文本 → 结构化事实：抽取且每条可溯源        |
| 4 | 数据 → 交付物：填进模板，并有可核对的准确率    |
| 5 | 后端 → 能用：界面接上，全链路可演示        |
| 6 | 能跑 → 能交接：测试、复现、交接          |

第 1 周不分档（地基，两档同做）。第 2–4 周是数据链路三段。第 5 周合流前端。第 6 周只做验证与交接。

## 6. 偏航信号

本节是本文的主要用途。出现任一情况，说明方向已偏，回到第 3 节：

- 有人在花时间论证该不该换框架、换数据库
- 前端比后端链路先做完
- 第 N 周还在补第 N−2 周的东西
- 报得出准确率，换台机器复现不出来
- 增量任务变成"多做几个文件"，而不是"标准更高"
- 第二档成员在等一份更细的步骤，而不是自己写三个方案选一个
- 单周投入明显超出周均 8–10 小时
- 第 6 周仍在加功能

## 7. 治理

- **维护分工**：本文由部门维护；各周任务书按本文方向编写，细节自定，不必与本文互相引用校验。
- **两档流动**：第一档可随时升到第二档，不设门槛；第二档不回落——选定即按第二档交付，两段都做、都算数。
- **过程观察**：每两周看三个数——按期完成率、卡点分布、第二档留存率。这三个数决定任务书该加还是该减，不看口头反馈。
- **变更条件**：只有两种情况改本文——周期变了，或对象基础变了（如零基础比例显著上升）。其余改进一律落在任务书，不动方向。
