# A23 核心功能说明

## 从文档到工作簿

Vue 工作台通过同源 HTTP 请求调用 FastAPI。解析器将四种格式转换成统一文档块。抽取事实和源块写入 SQLite。填写器读取数据库快照和原始模板，输出 Excel 与逐格决策。评估脚本读取结果和独立依据，验收命令检查产物、版本及数值。工作台通过结果标识和 Excel 行列号查询单格详情。

| 模块 | 输入与职责 | 输出 |
| --- | --- | --- |
| `parsers.py` 与各格式解析器 | 按后缀分派。TXT/MD 读 UTF-8，跳过空行并保留行号。DOCX 按文档顺序返回段落和表格格子。XLSX 流式读行，保留列名 | `ParsedDoc(file, blocks)`。每块含 `type`、`text`、`locator` |
| `extractor.py` | 以块号分批，请求通用或指标清单抽取。验证事实字段、当前批次的块号、连续原话和原值。保留指标原名，记录归并键与期次 | `count`、`kept`、`rejected`。CLI 可保存 Prompt 摘要、逐批原始响应、试次和去留 |
| `store.py` | `documents` 保存名称、字节和摘要；`blocks` 按文档与块号保存类型、文本和定位；`facts` 引用块号并保存模式、原指标、值、单位、原话、期次、口径 | 同一文档与模式按事务替换。相同原文字节和块布局可保留其他模式的事实 |
| `fill_spec.py` 与 `filler.py` | 按主体、归并指标、期次、口径查询候选。同值采用一条可回查记录，异值保留候选并等待指定来源。01 只取各城市正文段匹配的指标与单位，03 按日期和国家读取原表 | 两个固定 Excel 输出文件及各自逐格 JSON |
| `evaluate.py` 与 `check_dataset.py` | 前者比较独立参考工作簿，后者对公开样本从源文档另读预期。按坐标记录漏填、误填和填错。日期归一到年月日 | 来源标明的报告、行格统计、比率和差异明细 |
| `acceptance.py` 与 `verify.py` | 检查报告与工作簿、逐格 JSON、数据库的一致性。加载权威数值判据。整体验收运行 pytest、同库重填、空库重建和破坏性用例 | 用退出码判定。失败信息包含场景、字段、期望、实际和排查文件 |

## 版本与逐格证据

`result_id` 来自源版本、模板版本、填入值和逐格决策的内容摘要。同库输入相同时，重复写入得到同一内容标识。`run_id` 对应一次填写，`workbook_sha256` 标识该工作簿的实际字节。XLSX 保存时间可能改变字节摘要，耗时同样随运行变化。

`GET /reports` 只读取与本次运行及工作簿摘要一致的评分。服务配置参考目录或指定公开数据源后，`POST /fill` 在写表时生成匹配的评分文件。`GET /cells` 按坐标读取决策，再用库内原文及其摘要核对证据。明确拒填的格保存原因，逐格数据中不存在的格显示「没有记录」。从页面下载时带内容标识，下载接口验证工作簿内容。

## 操作方式与范围

已有库演示执行解析、填写和读报告。空库路径为 01 抽取事实或 03 导入原表后填写。01 发起在线请求前经使用者确认。输入更新后，原文摘要约束填写，证据版本改变会提示重新填写。原始模板以只读输入使用。

两套模板有固定字段、目标单位与排序规则。01 的数字受抽取与口径识别影响，03 使用 XLSX 源数据。未提供正式参考表时可运行独立原文核对与合成参考评分。新格式、通用 Word/Excel 编辑、异步任务接口和五模板评测的范围见竞赛规划。[README](../README.md) · [六周验收记录](六周验收记录.md) · [竞赛扩展规划](竞赛扩展规划.md)
