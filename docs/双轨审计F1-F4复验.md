# 双轨审计 F1–F4 复验

上一轮补全提交为 `0be27a0`。本轮继续六周训练整改，按新版双轨审计逐一验证 F1–F4。TXT 使用原有响应离线重放。[上一轮补全记录](双轨审计补全记录.md)

| 审计问题 | 本轮整改和实测 |
| --- | --- |
| F1 指标错配 | 01 用数值在原文中的位置定位相邻指标。模型把财政收入 10 亿元标成 GDP，使用完整引文、数字截短引文或含两个指标的引文都被拒填；GDP 合法同义词与数字在指标前的公开表达可填写。 |
| F2 季度值误填 | 从数值所在分句及紧邻口径标题查季度、半年和月份。模型漏标或把半年误标为全年时均拒填，全年与季度并列时仍可选全年值。拒填详情保存原文口径及来源。两份公开城市历史事实重填均保持 100 行、500 格。 |
| F3 不完整批次通过 | 对照真实原文重建块序列、提示词并逐批离线重放，带库验收同时比对实际事实。删尾批同时更新摘要、重复批次、改文档名及删除凭证的受控反例均失败；真实留档的四批、400 条事实保持一致。归档验收覆盖原文、批次、凭证、报告及工作簿，库内事实校验在完整运行目录执行。 |
| F4 参考判据串用 | 综合入口接受独立参考判据和经核验的观察点，要求同库、重建与判据均绑定同一对参考摘要。受控 100×5 参考将 B2 调整一格后得分 0.998，对应配置通过；改参考摘要或交换评分依据失败。公开原文判断仍使用原判据。 |
