# A23 开发规格

## 交付范围

本次按六周挑战档交付，先完成引导档，再覆盖四种文档、多源候选归并、两种模板填写、逐格追溯和可复现验收。开发与回归先使用合成样例，任务书指定的原始材料到位后另行验收。正式赛题另有自然语言文档操作、Word 模板、异步调用与比赛样本评测等要求，本次交付以训练任务书为准。[六周总规划](../六周任务/两档难度总规划.md) · [A23 赛题](../六周任务/第十七届服务外包比赛A23赛题.md)

## 技术栈

| 部分 | 技术与约束 |
| --- | --- |
| 后端 | Python 3.14 项目内 `.venv/`，FastAPI、Pydantic、Uvicorn，接口以 `backend/main.py` 为入口 |
| 数据 | Python 标准库 `sqlite3`，数据库默认位于 `backend/data/a23.db` |
| 文档 | TXT、Markdown 按 UTF-8 解码并接受 BOM，DOCX 使用 python-docx，XLSX 使用 openpyxl |
| 模型 | httpx 调用 DeepSeek Chat Completions，使用 `deepseek-flash`、temperature 0、JSON 输出、60 秒请求超时。密钥读取 `DEEPSEEK_API_KEY`，支持 `backend/.env` |
| 前端 | Vue 3、Vite、JavaScript、浏览器原生 fetch。使用现有 Node.js 和 npm，FastAPI 同源托管构建产物 |
| 验收 | pytest、FastAPI TestClient、合成参考表评分与公开样本原文核对。在线抽取由命令或交互显式发起 |

## 代码结构

| 路径 | 职责 |
| --- | --- |
| `backend/main.py`、`schema.py`、`config.py` | HTTP 边界、共享数据契约、文件路径与配置 |
| `backend/parser_text.py`、`parser_docx.py`、`parser_xlsx.py`、`parsers.py` | 统一文档块模型与后缀分派 |
| `backend/extractor.py`、`store.py` | 批量调用模型、校验证据、归并指标、事务化存储与查询 |
| `backend/fill_spec.py`、`filler.py`、`evaluate.py` | 模板映射与拒填规则、写表和溯源、独立评估 |
| `backend/check_extract.py`、`check_dataset.py` | 记录模型逐批原始响应与去留，比较两个独立实验，重放历史响应或城市事实，核对公开原文 |
| `backend/criteria.py`、`acceptance.py`、`verify.py` | 加载唯一数值判据文件，校验文件和报告版本，组合 pytest、合成双模式及破坏性验收 |
| `frontend/src/App.vue`、`api.js` | 单页演示和统一请求入口 |
| `doc/`、`backend/data/`、`docs/` | 只读的任务书输入、运行产物、项目说明 |

## 代码风格

Python 用 4 空格缩进，文件、函数和变量用 `snake_case`，类型用 `PascalCase`，模块常量用 `UPPER_SNAKE_CASE`。模块边界补全参数和返回类型。Vue 使用单文件组件与 `<script setup>`，JavaScript 用 2 空格缩进，函数和响应式变量用 `camelCase`。注释说明业务判据、单位或顺序的原因。用户可见提示用中文，接口字段沿用任务书。

同一条规则只定义一次。HTTP 层负责参数校验和错误转换，SQL 在存储层用参数占位符。路径从模块或指定数据目录计算，支持中文文件名。模板另存为输出，评估参考答案只经评估模块读取。等待模型时避免持有数据库写事务，所有批次成功后按 `doc + mode` 事务替换事实。

## 功能与验收

| 功能 | 实现与检查 |
| --- | --- |
| 文档解析 | `POST /parse` 接收四种格式并返回 `file` 和 `blocks`。TXT、MD 跳空行且保留原行号。DOCX 保持段落与表格顺序，为段落和实际单元格分配独立定位。XLSX 只读流式遍历，块文本保留列名，跳过全空行。坏文件或未知后缀给出可读错误。[第 2 周](../六周任务/第二周任务.md) |
| 事实抽取 | `POST /extract` 接收 `file` 与逗号分隔的 `metrics`，支持通用和清单模式，返回 `doc, mode, count, kept, rejected`。块号必须在当前批，原话须为对应原文的连续片段，数值须能在原话中核对。保留原始指标与单位，入库另存归并键、期次和出处。XLSX 解析完整入库，发送模型的行数受单独的抽取上限约束。[第 3 周](../六周任务/第三周任务.md) |
| 多源归并 | 以主体、归并指标、期次和统计口径对齐候选，保留原指标与每条出处。期次优先从数值所在句取得，其次按任务书继承最近年份标题。同键同值可采用一条可追溯记录。同键异值且没有明确的来源优先级时保留候选并拒填。缺失与零分别处理。[第 3 周](../六周任务/第三周任务.md) |
| 01 城市经济模板 | 依据原文正文顺序定位城市，按四项指标映射、数值类型和单位写入 B–E 列。原模板只读，每个结果格可查来源。评估按 A2:E101 的行列对齐，记录 100 个城市的行序、单元格准确率、行完整率及错格清单。[第 4 周](../六周任务/第四周任务.md) |
| 03 历史疫情统计模板 | 2020-07-01 至 2020-08-31，日期升序，同日国家名升序。仅从匹配日期和国家统计口径的结构化数据写值，地区叙述保留作范围判断依据。逐格记录填写或拒填原因，日期写 Excel 日期，缺值保留为真空。正式验收为 2542 行 × 7 列，应填 17464 格、应空 330 格，分别计算对格率、误填率和漏填率。[第 4 周](../六周任务/第四周任务.md) |
| 填写与演示 | `POST /fill` 接收文档名、模板名与可选原文摘要，JSON 仍返回 `rows, cells_written, cells_empty`，响应头提供内容标识和服务端填写耗时。配置 `A23_REFERENCE_DIR` 时读取该目录的 `参考_01.xlsx` 或 `参考_03.xlsx` 生成评分。配置 `A23_SOURCE_CHECK_ROOT` 时，字节匹配的公开样本可生成独立原文核对报告。`GET /reports` 只读本次批次与工作簿摘要匹配的报告。`GET /files` 仅下载 `filled_*.xlsx`，页面下载附结果标识。`GET /cells` 是两套场景共用的追溯入口。[第 5 周](../六周任务/第五周任务.md) |
| 回归与交接 | 同库复验按精确值判定。重建库后，解析块数和确定的模板行数仍精确，受模型影响的计数和率用有实测依据的区间。验收命令统一读取判据并用退出码报告结论，错误输出指出判据、预期值和实测值。[第 6 周](../六周任务/第六周任务.md) |

任务书的固定块数、行数和分母仅适用于指定样本。合成样例用于检查解析、证据校验、候选冲突、真空与零、填表、比对和接口。正式验收需要原始输入、模板、参考结果、本地密钥，以及可核对的真实运行记录。

运行模型由任务书的 `deepseek-chat` 更新为 `deepseek-flash`。真实抽取的验收记录需注明模型名，重建库复验的区间须依据该模型的实测数据。[DeepSeek Chat Completions](https://api-docs.deepseek.com/api/create-chat-completion)

## 实测记录

本轮在 macOS Apple Silicon 独立 Clone 和新虚拟环境中完成构建、测试、01 预置库与 03 空库的 Chrome 演示。真实 TXT 两轮的模型响应、过滤差异和重放结果已保存。两份历史城市抽取分别用于同库与重建原文核对，正式参考表和 Windows 实机结果仍待补。[六周验收记录](六周验收记录.md)

实验日志记录源文本的原始模型响应，保存在 CLI 指定数据目录下的 `extraction-runs/`。提示词保存摘要。日志与报告均使用本地文件，HTTP 抽取端点只返回本次的汇总计数。SQLite 写入由 `Store.save` 事务处理。Web 进程内串行填写以保护固定输出文件，隔离验证和命令行评分使用独立数据目录。

配置的参考表不可用时，填写仍返回可以下载的结果。评分异常写入服务日志，HTTP 响应头 `X-A23-Score-Status: failed` 供工作台显示自检错误。缺少当前版本评分时 `GET /reports` 返回 404。

TXT、MD 的 `block_no` 使用原文行号，跳过空行后编号可以不连续。DOCX、XLSX 使用从 1 开始的文档内块序号，原文位置由 `locator` 保存。模型请求、SQLite 与来源查阅共用这套编号。[第三周任务](../六周任务/第三周任务.md)
